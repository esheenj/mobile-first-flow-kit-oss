# Community conduct

Be respectful, specific and constructive. Critique ideas and code without harassment, threats, discrimination or disclosure of personal information. Keep discussions relevant and make room for contributors with different experience levels.

Maintainers may edit or remove harmful content, close disruptive discussions or restrict participation. Report conduct concerns through an established private maintainer channel; if none is available, request one without identifying affected people publicly. Apply the same care in issues, pull requests and linked project discussions.
