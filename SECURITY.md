# Security reporting

This project runs locally and has no hosted authentication, telemetry or production service. Treat all supplied data as untrusted. Validation is intentionally bounded and does not establish complete application security.

Do not disclose credentials, personal information or vulnerability exploitation details in public issues. Use GitHub's **Report a vulnerability** option on the Security tab if available. If it is unavailable, open a nonsensitive issue requesting a private reporting channel; share details only after that channel is established. A reporting feature is not claimed enabled until GitHub confirms it.

The current main branch is maintained on a best-effort basis. There is no guaranteed response time or security certification. Ordinary nonsensitive bugs belong in the issue form.
