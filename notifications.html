Make notifications dismissible and reversible.

Compare priority, dismissal and snooze states on invented in-app notices. This is not push notification software. Snooze changes only this page's in-memory state; there are no timers, device permissions, actual future reminders, accounts or network calls.

Try the state transitions

    Design principle

    Make interruption severity visible, let people dismiss and recover, and provide explicit status feedback. Real notification design requires user consent, frequency controls and research that this example does not provide. Model, tests and contributions.
